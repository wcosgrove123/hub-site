Skills

What each skill asks, where it shows up in this unit, and how we practice it.

The first cards are the College Board's numbered skills and its three reasoning processes (causation, comparison, continuity and change). The rest are AP question types and the methods we use in class.

  • College Board skill 1.B

    Explain a historical concept, development or process

    What it asks
    Say what something was and why it mattered.
    Where it shows up in this unit
    Topic 4.13 Society of the South; Topic 5.2 Manifest Destiny
    How we practice it in class
    Draw a term; give a one-sentence definition and one “which mattered because.”

  • College Board skill 2.B

    Explain point of view, purpose, historical situation and/or audience

    What it asks
    Explain how who made a source, for whom, why and when shapes it.
    Where it shows up in this unit
    Topic 5.5 Regional differences (also Topics 4.3 and 4.4 earlier)
    How we practice it in class
    HAPP a source card in two minutes; pods swap and check one letter each.

  • College Board skill 3.B

    Identify the evidence used in a source to support an argument

    What it asks
    Find the proof an author uses for a claim.
    Where it shows up in this unit
    Topic 4.11 An Age of Reform
    How we practice it in class
    Underline the claim, circle the evidence, then say whether the evidence fits.

  • College Board skill 3.C

    Compare the arguments or main ideas of two sources

    What it asks
    State each source's main idea, then a similarity or difference.
    Where it shows up in this unit
    Topic 5.3 The Mexican–American War
    How we practice it in class
    Paired cards: Polk and Douglass, Webster and Swisshelm, Vallejo and Cortina.

  • College Board skill 3.D

    Explain how claims or evidence support, modify or refute a source's argument

    What it asks
    Test an argument against evidence.
    Where it shows up in this unit
    Topic 4.12 African Americans in the Early Republic
    How we practice it in class
    Take one claim from a source card. Find one piece of evidence that supports it and one that complicates it, then say which is stronger.

  • College Board skill 4.B

    Explain how a development fits a broader historical context

    What it asks
    Connect a specific event to the bigger process around it.
    Where it shows up in this unit
    Topics 4.9, 5.1, 5.4 and 5.7
    How we practice it in class
    Name a broad development, add one specific piece of evidence, and link them in a sentence.

  • College Board skill 5.B

    Explain how one development relates to another

    What it asks
    Make and explain a connection, by cause, comparison or change.
    Where it shows up in this unit
    Topic 4.10 Second Great Awakening; Topic 5.6 Failure of Compromise
    How we practice it in class
    Build a chain: each effect becomes the next cause, with a “which led to” between.

  • College Board skill 6.C

    Use historical reasoning to explain relationships among pieces of evidence

    What it asks
    Organize evidence with causation, comparison or continuity and change.
    Where it shows up in this unit
    Unit essay prompt (Topic 5.12)
    How we practice it in class
    Pick two evidence cards and state how they relate (cause and effect, before and after, same or different).

  • Reasoning process

    Causation

    What it asks
    Why did it happen, and what did it lead to?
    Where it shows up in this unit
    Topics 4.10, 4.13, 5.2, 5.3, 5.6 and 5.7
    How we practice it in class
    Evidence comes in pairs: an example of the cause and an example of the effect.

  • Reasoning process

    Comparison

    What it asks
    How were two things alike or different, and why?
    Where it shows up in this unit
    Topics 4.11, 5.4 and 5.5
    How we practice it in class
    Name both sides, then the similarity or difference, then why it matters.

  • Reasoning process

    Continuity and change

    What it asks
    What stayed the same and what changed, from when to when?
    Where it shows up in this unit
    Topics 4.12 and 5.1
    How we practice it in class
    Continuity: one example before and one after showing the same thing held. Change: from x to y.

  • SAQ

    Short answer (ACE)

    What it asks
    Address the task, cite one specific piece of evidence, explain how it answers.
    Where it shows up in this unit
    Every topic
    How we practice it in class
    Pods answer one part in a set time, then rotate papers and score one row.

  • SAQ with sources

    Short answer with one or two secondary or primary sources

    What it asks
    Read a historian's or a period source's claim, then support or challenge it with outside evidence.
    Where it shows up in this unit
    Every topic
    How we practice it in class
    Give one claim card; pods add one piece of evidence that supports it and one that challenges it.

  • MCQ sets

    Stimulus-based multiple choice

    What it asks
    Three or four questions on one source: situation, audience, cause, effect, comparison.
    Where it shows up in this unit
    Every topic
    How we practice it in class
    Before looking at choices, pods predict the answer type (cause, effect, audience...).

  • Cartoons and images

    Reading a political cartoon or image

    What it asks
    Read labels, symbols and exaggeration to find the point of view and the audience.
    Where it shows up in this unit
    Topics 5.6 and 5.7
    How we practice it in class
    Name what is labeled, who is drawn sympathetically, and who would buy the paper it ran in.

  • Maps and data

    Reading maps, charts and election results

    What it asks
    Find the pattern, then explain the cause or effect.
    Where it shows up in this unit
    Topics 5.2, 5.6 and 5.7
    How we practice it in class
    Compare the 1856 and 1860 electoral maps; say what changed and why.

  • LEQ thesis

    Thesis and line of reasoning

    What it asks
    Although [y], [x, to the extent of z] because [reason].
    Where it shows up in this unit
    Unit prompt: debates over slavery and the Civil War
    How we practice it in class
    Write the although clause first, then the claim with its extent.

  • Theme funnel

    Choosing evidence by theme

    What it asks
    The prompt's theme decides which domains the evidence must come from.
    Where it shows up in this unit
    Every topic
    How we practice it in class
    Draw a theme and a prompt; pods name two domains and one piece of evidence for each.
